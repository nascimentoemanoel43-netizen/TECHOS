## Descrição

O TechOS é um sistema de gerenciamento de ordens
de serviço desenvolvido para a empresa TechServices.

O sistema permitirá cadastrar clientes,
equipamentos e ordens de serviço, além de
acompanhar o andamento dos atendimentos.

## Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript
- Node.js
- Express
- PHP
- MySQL
- Git
- GitHub

## Objetivo

Desenvolver uma aplicação web para facilitar
o gerenciamento de serviços técnicos.
