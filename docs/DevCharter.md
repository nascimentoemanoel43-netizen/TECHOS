# Dev Charter (Acordo de Desenvolvimento) — TechOS

Este documento estabelece o código de conduta, o fluxo de trabalho e os padrões técnicos seguidos no desenvolvimento do sistema **TechOS** para o SENAI Belo Jardim.

## 1. Padrões de Versionamento (Git / Conventional Commits)
Todas as alterações no código-fonte ou documentação devem seguir rigorosamente o padrão de Conventional Commits:
- `feat:` Novas funcionalidades.
- `fix:` Correção de bugs.
- `docs:` Alterações exclusivas na documentação.

## 2. Fluxo de Trabalho (Branching Strategy)
- A branch principal do repositório é a `main`.

## 3. Padrões de Qualidade
- Atendimento aos Requisitos Não Funcionais baseados na ISO 25010 (`docs/RNF.md`).
