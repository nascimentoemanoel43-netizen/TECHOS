# Matriz de Stack Tecnológica — TechOS

Este documento consolida as tecnologias escolhidas para o desenvolvimento do sistema de gestão de Ordens de Serviço (TechOS).

## Camadas da Arquitetura

| Camada | Tecnologia Escolhida | Justificativa |
| :--- | :--- | :--- |
| **Frontend** | HTML5, CSS3, JavaScript (Vanilla) | Leveza, facilidade de manipulação do DOM e compatibilidade total com navegadores modernos sem dependências complexas. |
| **Backend** | Node.js / PHP | Processamento de requisições assíncronas e regras de negócio para integração com o banco de dados. |
| **Banco de Dados** | MySQL | Robustez, suporte a relacionamentos relacionais (tabelas de Clientes, Equipamentos e OS) e facilidade de integração local (XAMPP). |
